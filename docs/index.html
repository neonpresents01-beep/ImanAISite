سوالات پرتکرار

اگه سوالی داری، اینجا جوابش هست

ImanAccount چیه و چه فرقی با هلو داره؟ +
ImanAccount یه نرم‌افزار حسابداری مدرن با هوش مصنوعی داخلیه. ۵ برابر سریع‌تر از هلو، با رابط کاربری ۲۰۲۵، و ۸۰٪ ارزون‌تر. علاوه بر حسابداری، انبارداری، حقوق و دستمزد و AI داره.
چطور نصب کنم؟ +
فایل Setup رو دانلود کن، دابل‌کلیک کن، Next بزن. کمتر از ۲ دقیقه نصب میشه. بعد از نصب، Wizard راه‌اندازی اولیه همه چیز رو تنظیم می‌کنه.
نسخه آزمایشی چقدره؟ +
۳۰ روز رایگان، بدون کارت اعتباری، بدون تعهد. اگه راضی نبودی، پولت برمی‌گرده. توی این ۳۰ روز همه قابلیت‌ها رو داری.
اطلاعات من امنه؟ +
بله. اطلاعات روی کامپیوتر خودت ذخیره میشه، نه سرور ما. سیستم لایسنس با RSA 4096 و رمزنگاری AES-GCM. رمزها با bcrypt محافظت میشن — سطح بانکی.
پشتیبانی چطوره؟ +
پشتیبانی ۲۴/۷ از طریق تلگرام و تلفن. میانگین پاسخ‌دهی زیر ۵ دقیقه. برای کاربران حرفه‌ای و سازمانی، پشتیبانی اختصاصی داریم.
موبایل هم داره؟ +
نسخه موبایل در Q1 ۱۴۰۵ منتشر میشه. برای اطلاع از جدیدترین اخبار، تو تلگرام و اینستاگرام ما رو دنبال کن.
با مودیان کار می‌کنه؟ +
بله، ماژول مودیان در Q3 ۱۴۰۵ اضافه میشه. الان جداول و ساختار آماده‌ست، فقط اتصال به API مونده.
چطور از هلو مهاجرت کنم؟ +
تیم پشتیبانی ما کمکت می‌کنه. داده‌هات از هلو استخراج میشه و به ImanAccount منتقل میشه. این سرویس برای مشتریان حرفه‌ای رایگانه.
روی ویندوز ۷ کار می‌کنه؟ +
بله، ما نسخه 32-bit هم داریم که روی Windows 7 SP1 و بالاتر کار می‌کنه. نسخه 64-bit برای ویندوز ۱۰ و ۱۱ پیشنهاد میشه.
پول برگشت داره؟ +
بله. اگه توی ۳۰ روز اول راضی نبودی، ۱۰۰٪ پولت برمی‌گرده. بدون سوال، بدون دردسر.
